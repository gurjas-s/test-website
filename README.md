# Look Up

A single-page website about stargazing and the night sky.

**Look Up** is a quiet, dark-themed page covering why looking up matters, how curiosity and wonder grow when we stargaze, a few famous constellations to find, and a simple beginner guide to start stargazing tonight.

## Run locally

Open `index.html` in any browser — no build step, no dependencies.

## Stack

- One self-contained `index.html` (inline CSS + JavaScript)
- Animated twinkling starfield drawn on a `<canvas>`
- No external dependencies
